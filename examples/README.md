# Examples

Example Lua scripts for `beca run` / the `beca.*` runtime.

- `voice_sdk.luau` — example for controlling `VoiceCaptureWindow` via `beca.ui.window` + `beca.voice`/actions.
- `behavior.luau` — reference behavior script.

Run:
```bash
beca run examples/voice_sdk.luau
```
User config/theme and scripts: `$XDG_CONFIG_HOME/beca/` (see `docs/schema/`).
