# Exemplos

Scripts Lua de exemplo para `beca run` / runtime `beca.*`.

- `voice_sdk.luau` — exemplo de controle de `VoiceCaptureWindow` via `beca.ui.window` + `beca.voice`/ações.
- `behavior.luau` — script de comportamento de referência.

Executar:
```bash
beca run examples/voice_sdk.luau
```
Config/tema e scripts do usuário: `$XDG_CONFIG_HOME/beca/` (ver `docs/schema/`).
